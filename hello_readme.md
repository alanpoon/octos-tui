# Hello README

This is a friendly copy of the octos-tui README. 👋

---

`octos-tui` is a standalone terminal UI client for the Octos UI Protocol.
It is a chat-first coding client that you point at an `octos serve` backend.

## Quick Install

```bash
npm install -g @octos-org/octos-tui
# or
brew install octos-org/tap/octos-tui
# or from source
cargo install --git https://github.com/octos-org/octos-tui octos-tui
```

See [README.md](README.md) for the full docs.
